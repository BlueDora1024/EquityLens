# EquityLens v1.1.1

## 更新内容

- 修复长桥大股票池第一次运行部分失败、重复运行成功率才逐步提高的问题。
- 正确识别长桥 Quant 的 `429002` 限频响应，不再误报为内部供应商错误。
- 降低量化请求启动速度，并在限频时自动冷却、单路恢复，无需用户反复重跑。
- 加强瞬时服务错误和异常响应的有限重试；仍失败时继续提供整次 Yahoo 备用运行，结果不会混用两个数据源。
- 保持分析工作在独立子进程执行，等待期间窗口仍可移动和取消。

## What's Changed

- Fixed partial first-run failures in large Longbridge stock pools.
- Recognized Longbridge Quant business rate-limit code `429002` instead of treating it as an internal provider failure.
- Added safer request pacing, cooldown, and bounded single-lane recovery.
- Strengthened bounded retries for transient server and malformed responses while preserving whole-run Yahoo fallback without mixed data sources.
- Kept provider work isolated from the GUI process so the app remains responsive during longer runs.
