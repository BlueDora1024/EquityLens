# EquityLens v1.1.4

## 更新内容

- 修复应用在后台运行时再次点击图标无法恢复窗口的问题。
- 三个分析工具的进度改为连续、只前进不后退，保存完成前不会提前显示 100%。
- 修复后台休眠被误报为界面卡顿的问题。
- 富途质检现在会说明额度、授权、限频、超时或数据异常等真实原因。
- 减少全局证券、标签和股票池页面启动时的重复数据库读取。
- 统一切页、弹层、按钮和进度条的轻量动画，并收紧运行区高度与窄窗口布局。

## What's Changed

- Restored hidden or minimized windows when EquityLens is activated again.
- Made progress monotonic and smooth across all three analysis tools, reserving 100% for a completed save.
- Stopped background App Nap from being reported as a UI stall.
- Preserved clear, sanitized Futu quality-check reasons for quota, authorization, throttling, timeout, and malformed data failures.
- Reduced duplicate SQLite reads during master-data page startup.
- Unified lightweight page, modal, button, and progress transitions while tightening run-card sizing at default and minimum window sizes.
