# EquityLens v1.1.5

## 更新内容

- 修复 RS、拐点筛选和极值偏离重复运行时缓存命中长期显示为 0、并反复下载相同历史行情的问题。
- 新上市证券即使历史不足请求根数，也会记住供应商实际可提供的完整历史，不再永久重复请求。
- 运行前资源预检与实际执行统一使用同一套缓存判断，预计请求数更加可信。
- 资源确认弹层调整为更协调的宽高与间距，并使用短促淡入和轻微缩放过渡；小窗口下不会越界。
- 缓存状态改为“当前源完整命中”，并明确部分历史复用不会误算为完全免请求。

## What's Changed

- Fixed repeated downloads and permanently zero cache-hit counts across RS Strength, Turning Point, and Extreme Deviation runs.
- Treats the full history actually available for newly listed securities as authoritative, even when it is shorter than the requested window.
- Uses one shared cache-coverage rule for both resource estimates and execution, making request forecasts more reliable.
- Refined the resource confirmation dialog with balanced sizing, spacing, a short fade, and subtle scale transition that stays within compact windows.
- Clarified complete provider-specific cache hits while continuing to reuse partial history without overstating a full hit.
