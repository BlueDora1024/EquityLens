# 首次配置与设置设计

状态：v0.11 已实现；当前设置页为供应商、AI、外观和高级四个工作区，首次配置只展示
供应商与 AI 的必需路径。

## 1. 目标与边界

首次启动只解决两件事：

1. 选择并启用一个只读行情供应商；
2. 可选配置一个 OpenAI-compatible AI 服务。

可用行情供应商是进入软件的必要条件；AI 不是。AI 未配置或不可用时，全局证券、股票池及
三个确定性分析工具仍可正常使用，仅关闭 AI 分类兜底和手动 AI 解读。

普通用户不需要理解 Client ID、OAuth token、测试环境或开发者模式。

## 2. 用户流程

### 2.1 首次启动

应用读取本地配置状态：

```text
没有完成首次配置
    → 打开独立首次配置窗口
    → 选择长桥或富途
    → 完成候选供应商授权/登录与质检
    → 设为当前供应商
    → 解锁可选 AI 配置与质检
    → 写入完成标记
    → 打开主窗口的全局证券页
```

首次配置窗口关闭即退出应用，不允许绕过当前所选供应商质检进入空壳主界面。

首次配置采用两步式布局：

- 第一步“行情供应商”为必填；
- 第二步“AI 分析”为可选，但只在一个供应商质检并启用后解锁，可暂时跳过；
- 已完成的第一步可返回查看，但重新授权失败不能破坏仍有效的旧授权。

### 2.2 后续启动

后续启动先检查完成标记、当前供应商和相应本地材料。长桥检查 Client ID 与 SDK
token 文件；富途检查 OpenD 是否安装，但不要求它在应用启动前已经运行。材料存在
时直接打开主窗口并在后台做轻量健康检查。临时断网、OpenD 未运行或供应商短时
故障只显示“暂时离线”，不能锁死已经完成配置的应用；确认授权材料失效时才要求
重新完成该供应商配置。

首次配置完成后、主窗口落到“全局证券”时展示五步图片式使用引导：全局证券、标签
与股票池、三个分析工具、结果与历史、设置与网络恢复。每一步都用软件缩略图和强调
圈聚焦一个区域，只提供“上一步 / 下一步 / 完成”，不要求用户点击底层具体按钮。
用户关闭或完成但未勾选“不再提示”时，只关闭本次会话，下次启动仍会显示；勾选后
写入全局设置并永久停止自动提示。恢复默认会连同该选择清除。Scenario 和自动化测试
不自动弹出引导，避免遮挡确定性脚本。强调圈绑定缩略界面中五个真实目标控件，弹层
尺寸变化时重新计算，不使用容易漂移的比例坐标；图片区横纵比不得超过 1.85:1。

### 2.3 日常设置

主窗口左侧栏底部始终显示有 tooltip 和 accessible name 的设置齿轮，并支持
`⌘,`。设置窗口提供：

1. 行情供应商；
2. AI 分析；
3. 外观；
4. 高级。

长桥和富途配置可以同时保留，但任何时刻只能启用一个当前供应商。点击卡片只查看
候选配置；完整质检通过后“设为当前供应商”才可用，切换失败不覆盖原供应商。

外观页提供“跟随系统（默认）/浅色/深色”。切换即时应用到所有主页面和弹层，
选择保存到业务 SQLite 的本机设置中；恢复默认后重新回到“跟随系统”。外观页还
提供“再次查看引导”，它只打开当前会话的五步引导，不清除“不再提示”事实标记。
开发者模式、Scenario Lab 和诊断日志只在高级页出现，不进入首次配置流程。

设置窗口左下角固定显示次要危险操作“恢复默认…”，它不属于第三个设置分类，也不
与日常保存按钮并排。

高级页的“诊断日志”用于正式环境问题定位。它展示当前健康状态、磁盘占用、最近
事件，以及警告、错误、界面卡顿和慢 SQL 计数；支持按模块、级别和证券代码搜索。
查看和导出均在后台完成，不阻塞主线程。日志保留 7 天、总量最多 100 MiB，
单文件达到 5 MiB 后滚动；清理按最近访问/修改时间淘汰旧文件。用户可打开日志
目录、导出脱敏 ZIP，或经二次确认立即清空日志。

## 3. 长桥授权

长桥是两个内置只读行情供应商之一；Virtual Provider 不对普通用户显示。

用户点击“自动配置并授权”后：

1. 应用调用长桥动态客户端注册接口，注册公开 OAuth 客户端；
2. 暂存返回的非敏感候选 Client ID，但不在界面展示；
3. 使用 Longbridge SDK `OAuthBuilder(client_id)` 打开系统浏览器；
4. 用户在长桥页面登录并授权；
5. SDK 回调完成后用 `Config.from_oauth()` 创建配置；
6. SDK 将 token 保存到
   `~/.longbridge/openapi/tokens/<client_id>`，并负责自动刷新。

只有新授权及四项质检全部通过，才把候选 Client ID 原子切换为当前配置；此前有效的
旧 Client ID 和 token 不受失败尝试影响。

基础行情和公司资料由长桥授权自动包含。动态注册会声明本应用的集成 URI，授权请求
使用标准 `scope=4`，让官方确认页只保留自选列表这一项最小扩展权限；不申请账户
资产、资金明细、订单查询或下单权限，应用也不调用自选列表写接口。不得再依赖
`mcp-endpoint` 查询参数：长桥授权服务会在跳转时丢弃它，导致确认页回退为全权限
默认值。Token 不复制到 SQLite、Keychain、日志、历史、导出或诊断信息。

动态注册失败、用户取消和 OAuth 回调超时均保留在当前步骤，展示稳定错误原因和
“重试”动作，不把底层异常或敏感请求内容直接呈现给用户。

## 4. 长桥质检

首次授权后必须真实完成四项检查：

| 检查 | 验收 |
| --- | --- |
| OAuth | SDK 能从 token 创建配置，必要时可刷新 |
| 交易日 | 能得到最新一个已完整收盘的美股交易日 |
| 公司资料 | 能得到 `AAPL.US` 的有效基础资料 |
| 日线行情 | 能得到 `AAPL.US` 最近的有效日 K |

四项全部通过才解锁“继续”。界面逐项显示等待、执行、成功或失败，失败项提供原因和
重试。质检不导入 AAPL，不写业务证券库，也不留下运行历史。

设置页支持“重新授权”和“重新质检”。重新授权前不主动删除旧 token；新授权成功
后再切换当前 Client ID。清除授权属于隐藏的高级操作，并明确区分本机 token 清理
和长桥账户侧撤销。

## 5. 富途 OpenD 与质检

富途不是浏览器 OAuth。第一次点击富途卡片必须弹出四节点时序图：安装
Futu OpenD → 在 OpenD 登录 → 本机只读质检 → 设为当前供应商。软件只连接
`127.0.0.1:11111`，不接收富途账号、密码或 token。

富途质检依次检查 OpenD 端口、最近完整交易日、AAPL 基础资料、行情快照、日 K
和历史 K 线额度。六项全过只表示候选可用，不自动破坏当前供应商；用户点击
“设为当前供应商”后才在一个 SQLite 事务中切换并重建 Provider。OpenD 未安装、
未运行或未登录时给出下载、打开和登录动作，不让主线程等待连接。

## 6. AI 配置

AI 页面包含：

- 等宽铺满连接区左右两半的 Base URL 与 API Key；
- 可编辑的 Model 下拉框；
- “获取模型”；
- “开始质检”；
- “暂时跳过”和“保存并进入软件”。

页面另提供 DeepSeek 官方 API Keys 入口。文案推荐先充值 10 元，并说明正常账号
创建 Key 通常只需 2–3 分钟；充值、账号和 Key 创建全部发生在 DeepSeek 官方页面，
软件不代收费用。

“获取模型”请求 OpenAI-compatible `GET {base_url}/models`。成功时填充模型列表；
服务不支持该接口或请求失败时，允许用户手工填写 Model ID。配置名称、供应商名称、
timeout 和 retries 不在首次配置页暴露。

AI 质检必须发送一次受硬预算限制的最小结构化分类请求，依次验证：

1. API 鉴权；
2. 所选模型可以响应；
3. 响应可解析为应用的分类结构。

能列出模型不等于质检通过。API Key 按现有产品决策写入全局配置 SQLite，不使用
Keychain，不进入日志或导出。AI 失败不影响当前供应商状态，也不阻止用户进入软件。

跳过后，触发 AI 分类或 AI 解读时显示“AI 尚未配置”，并可直接跳转到设置窗口的
AI 页面。

## 7. 状态模型与持久化

首次配置状态只保存事实，不保存页面进度：

```text
UNCONFIGURED
  └─ 所选供应商质检并启用 → PROVIDER_READY + 解锁 AI
       ├─ 跳过 AI → READY → 全局证券
       └─ AI 保存成功 → READY → 全局证券

READY
  ├─ 临时网络失败 → READY + OFFLINE
  └─ 授权材料缺失/确认失效 → UNCONFIGURED
```

持久化字段最小化：

| 存储 | 内容 |
| --- | --- |
| 全局配置 SQLite | 首次配置完成标记、当前供应商、候选状态、动态 Client ID、AI Base URL/Model/API Key |
| 全局配置 SQLite（界面偏好） | 使用引导“不再提示”事实标记 |
| Longbridge SDK token store | OAuth token |
| Futu OpenD | 富途账号、登录状态和行情权限；应用不复制这些内容 |
| `QSettings` | 窗口几何等纯 UI 偏好 |

不新增独立 onboarding 数据库，也不把 Provider 状态复制进每个分析模块。

## 8. 结构与复用

桌面层只负责页面状态和用户动作，调用共享应用服务：

- `OAuthRegistrationService`：动态注册、授权和当前授权切换；
- `ProviderQualityService`：执行四项质检并返回逐项结果；
- `AIModelDiscoveryService`：获取并规范化模型列表；
- `AIQualityService`：执行最小分类质检；
- `FirstRunStateService`：判断启动去向及提交完成状态。

这些服务由 GUI 和打包内 CLI 共用。CLI 增加非交互状态/质检入口，浏览器授权仍是
明确的交互命令；业务规则不得复制到 Qt 控件或 CLI 命令中。

## 9. 错误与恢复

- 所有外部错误映射为稳定错误码、简短原因和一个明确恢复动作；
- 认证失败不自动重试，瞬时网络错误按现有有限退避策略处理；
- OAuth、AI 和 Provider 状态彼此隔离，一个服务失败不清空另一个服务配置；
- 保存配置采用事务；保存失败不关闭窗口；
- 后台健康检查不弹阻塞对话框，只更新状态并在用户执行相关操作时解释；
- API Key、token、Authorization header、代理凭据、完整 AI 请求/响应和业务
  数据不得进入日志或诊断导出；证券代码允许记录。

## 10. 恢复默认

设置窗口左下角提供“恢复默认…”。它是本机全量重置，不是只恢复界面偏好。执行后
软件必须回到从未使用过的状态，并在重启后重新进入首次配置。

### 10.1 清除范围

- 正式业务 SQLite：全局证券、分类、股票池、工具结果、历史及其他业务数据；
- 共享行情缓存、临时文件和应用诊断日志；
- 全局配置 SQLite：首次配置标记、当前 Client ID、AI Base URL/Model/API Key；
- 本应用当前 Longbridge Client ID 对应的 SDK token 文件；
- 本应用的 `QSettings`，包括窗口位置、尺寸和界面偏好。

不删除安装的 `.app`、用户主动导出的文件，也不修改长桥账户、持仓或交易数据。
恢复默认同样不会退出、清空或修改 Futu OpenD 中的富途账号和行情权限。
删除本机 token 代表本应用退出授权，但不保证撤销长桥账户侧已经授予的 OAuth
许可；如需彻底撤销，用户仍应在长桥账户安全设置中操作。

失败的候选 OAuth 授权必须立即清理其候选 token；成功切换新授权后清理旧 Client
ID 对应的 token。这样恢复默认只需处理当前授权，不遗留本应用创建的可用 token。

### 10.2 二次确认

第一次确认展示不可恢复的清单、受影响的记录数量，并明确提示“应用将关闭并重新
进入首次配置”。主按钮使用“继续恢复”，默认焦点放在“取消”。

第二次确认要求用户手工输入 `恢复默认`。只有完全匹配时才启用红色按钮
“清空全部数据并重启”；不提供记住选择或跳过确认。

确认后禁止新的写操作，取消并等待后台任务结束，关闭数据库，按应用拥有的明确路径
清除数据，然后自动重启。清除成功前不得显示完成；任一关键路径清除失败时不静默
宣称已恢复，并给出稳定错误原因。重置流程不得记录即将删除的密钥或 token。

## 11. 测试与验收

### L0–L1：单元与契约

- 启动状态矩阵；
- 动态注册响应、取消、超时和错误脱敏；
- 长桥四项、富途六项质检的全成功及逐项失败；
- `/models` 成功、无接口、空列表和手工 Model ID；
- AI 最小分类质检及 secret 不泄露；
- 配置事务与旧授权保留。
- 使用引导五张图、前后切换、关闭后下次重现及“不再提示”持久化。
- 恢复默认清单、路径白名单和两次确认状态；
- 清除过程不得触碰导出目录、其他 Longbridge Client ID、Futu OpenD 数据或应用安装包。

### L2：应用集成

- 全新临时 HOME 必须出现首次配置；
- 未通过 Provider 质检不能打开主窗口；
- AI 跳过后可进入，AI 动作正确跳转设置；
- 已配置且离线时仍能打开主窗口；
- 授权材料缺失时重新进入首次配置；
- GUI 与 CLI 使用同一服务和隔离数据库。
- 完整重置后证券、历史、缓存、AI 配置和当前 OAuth token 均不存在；
- 重启后必须进入首次配置，重置中断不得报告成功。

### L3：Qt 冒烟

- 首次配置两步切换、关闭退出和焦点顺序；
- Provider 未通过时 AI 导航与底部动作不可绕过，完成后默认落地全局证券；
- 主窗口齿轮与 `⌘,` 打开同一设置窗口；
- 首次配置完成后打开图片式引导；980×680 下图片、圈选和底部动作不能溢出；
- 首次配置只有供应商和 AI 两步；日常设置另含外观与高级；
- 状态、错误、重试、手工 Model ID 和可访问性文案可见。
- “恢复默认…”位于设置窗口固定危险区，必须完成文字二次确认。

### L4：显式真实质检

- 动态注册与浏览器 OAuth；
- token 落在 SDK 默认路径且可刷新；
- 四项长桥质检；
- Futu OpenD 安装、登录、本机端口和六项只读质检；
- 用户配置的 AI 模型发现和最小分类；
- 打包后的 Intel `.app` 重复启动及重新授权。
- 打包应用恢复默认并自动重启后呈现首次配置。

真实测试受现有硬预算约束，默认自动化不得读取用户 token、API Key 或生产数据库。

## 12. 明确不做

- 不要求用户创建或填写 Client ID；
- 不支持手工粘贴 Longbridge token；
- 不创建富途交易上下文，不读取账户、资产、持仓、订单，也不执行交易；
- 不接入 macOS Keychain；
- 不在首次启动展示开发者、Mock、timeout、批量上限等内部参数；
- 不因 AI 未配置而禁用确定性分析；
- 不在启动时执行完整行情质检或阻塞式网络请求。
- 不删除用户导出文件，不清空其他软件的 Longbridge token，不把本机清理描述为
  已完成长桥账户侧 OAuth 撤销。
