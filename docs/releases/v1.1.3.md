# EquityLens v1.1.3

## 更新内容

- 修复全局证券编辑业务标签后列表跳回第一行的问题，可以连续处理长列表中的相邻证券。
- 修复全局标签删除一只关联证券后，其余删除按钮失效的问题；当前标签和滚动位置会继续保留。
- 同步修复股票池成员移除、标签/股票池重命名和标签批量添加中的同类列表复位风险。
- 增加真实桌面交互回归，覆盖长列表新增、移除和连续删除场景。

## What's Changed

- Fixed global securities jumping back to the first row after editing business tags.
- Fixed remaining delete actions becoming unresponsive after removing one security from a global classification.
- Applied the same stable-scroll behavior to watchlist member removal, collection renaming, and batch classification updates.
- Added real QML interaction coverage for long-list edits and repeated removals.
