# EquityLens v1.1.0

## 更新内容

- 新增后台检查更新，启动不再被网络检查阻塞。
- 新增“设置 → 高级 → 版本与更新”，可查看 Tag、Git SHA 和本机架构。
- 支持自动下载匹配 Intel 或 Apple Silicon 的安装包，校验 SHA256 后原位更新并重启。
- 更新过程只替换应用程序，不修改本地证券、配置、日志和历史结果。
- GitHub 正式版本现在强制附带简洁更新说明。

## What's Changed

- Added non-blocking update checks at startup.
- Added build identity and manual update controls under Settings → Advanced.
- Added architecture-aware download, SHA256 verification, in-place replacement, rollback, and relaunch.
- User databases and settings remain outside the application bundle and are never modified by updates.
